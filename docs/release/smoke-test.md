# LinguaQuest Smoke Test Guide

A manual walkthrough to confirm every major user-facing feature works correctly
on a **fresh install** of the release APK before shipping to Google Play.

## Pre-requisites

- App installed from the release APK (not a dev build)
- Either:
  - **Online mode**: Server running via `docker compose` and `API_BASE_URL` set
  - **Demo/mock mode**: APK built without `API_BASE_URL` (default offline mode)
- A test email address you can receive mail at (online mode only)
- Device or emulator running Android 8.0+ (API 26+)

---

## Test 1: Registration + Email Verification

**Goal**: New user can sign up and verify their email via OTP before accessing the app.

**Steps**:
1. Open the app on a fresh install (no existing account).
2. Tap **Register** on the auth screen.
3. Enter a display name, a valid email address, and a password (min 8 chars).
4. Tap **Create Account**.
5. Expect: app navigates to the **Verify Email** screen showing the email address.
6. **Online mode**: Check your inbox for the 6-digit code and enter it.  
   **Demo/mock mode**: Enter `123456` (the mock OTP always accepts this).
7. Tap **Verify**.

**Expected result**: App navigates to `/home` (the main shell with bottom tabs). No error dialogs.

---

## Test 2: Wordbook Selection

**Goal**: User can choose an HSK wordbook and the preference is persisted.

**Steps**:
1. From `/home`, navigate to the **Profile** tab (rightmost icon).
2. Tap **Settings** or look for study-plan / wordbook selector.
3. Confirm HSK 1, HSK 2, HSK 3, HSK 4, HSK 5, and HSK 6 are all listed.
4. Select **HSK 2** (or any book other than the default).
5. Navigate away and return.

**Expected result**: HSK 2 remains selected; lesson content on `/home` reflects the new wordbook.

---

## Test 3: Learning Session

**Goal**: User can complete a full lesson and earn XP.

**Steps**:
1. Navigate to the **Home** tab.
2. Tap **Start Lesson** (or the first lesson card).
3. Complete all quiz cards in the session (multiple-choice or fill-in).
4. Reach the end-of-lesson summary screen.

**Expected result**:
- XP is awarded and shown on the summary screen.
- Home screen progress bar updates.
- Streak counter increments if applicable.

---

## Test 4: Review Session (Spaced Repetition)

**Goal**: Previously-learned words appear in a review queue.

**Steps**:
1. Navigate to the **Training** tab.
2. If due-items exist, tap **Start Review**.
3. Complete at least 5 review cards (rate each as Easy/Good/Hard).
4. Reach the end-of-review summary.

**Expected result**:
- Cards are presented one at a time with the Chinese character and English definition.
- Rating each card does not crash.
- Summary shows how many items were reviewed.

> If no items are due yet (fresh account), complete Test 3 first and check again after a few seconds in mock mode (due dates are accelerated in demo mode).

---

## Test 5: AI Q&A

**Goal**: User can ask a free-form question in the AI Learning tab.

**Steps**:
1. Navigate to the **AI Learning** tab (brain/sparkle icon).
2. Select the **Q&A** mode or tap the chat input field.
3. Type a Chinese-learning question, e.g. "What is the difference between 的, 地, and 得?"
4. Tap **Send**.

**Expected result**:
- A response appears within a few seconds (mock response in demo mode).
- No crash or blank screen.
- Response is rendered in a chat bubble layout.

---

## Test 6: AI Sentence Analysis

**Goal**: User can submit a Chinese sentence and receive a breakdown.

**Steps**:
1. In the **AI Learning** tab, switch to **Sentence Analysis** mode.
2. Paste or type a Chinese sentence, e.g. `我昨天去了北京。`
3. Tap **Analyze**.

**Expected result**:
- Each word/character is shown with its pinyin and English gloss.
- Grammar annotations (subject, verb, time phrase, etc.) are highlighted.
- No error toast.

---

## Test 7: AI Fill-in-the-Blank (Cloze)

**Goal**: User can complete a cloze exercise generated by AI.

**Steps**:
1. In the **AI Learning** tab, switch to **Fill in the Blank** mode.
2. Tap **Generate** to create a new exercise.
3. A sentence with one or more blanks appears.
4. Select or type the correct answer for each blank.
5. Tap **Submit**.

**Expected result**:
- Correct answers are highlighted in green; incorrect in red.
- Score or feedback is shown.
- Tapping **Next** loads another exercise without crashing.

---

## Test 8: AI Essay Correction

**Goal**: User can submit a short paragraph for AI grammar/style feedback.

**Steps**:
1. In the **AI Learning** tab, switch to **Essay Correction** mode.
2. Enter a short paragraph in Chinese (2–5 sentences), e.g.:
   ```
   我是学生。我学习汉语很长时间。我的老师说我进步了很多。
   ```
3. Tap **Submit for Correction**.

**Expected result**:
- Annotated text appears with corrections marked (underline, color, or inline comment).
- A summary of errors and suggestions is shown below the annotated text.
- No timeout or crash.

---

## Test 9: Community — Post, Comment, Like

**Goal**: User can participate in the community feed.

**Steps**:
1. Navigate to the **Discover** tab.
2. Tap the **compose / +** button to create a new post.
3. Write a short message (e.g. "Day 1 of HSK 2!") and tap **Post**.
4. Confirm the new post appears in the feed.
5. Tap on any existing post to open it.
6. Tap the **comment** icon, write a comment, and submit.
7. Tap the **heart / like** icon on the post.

**Expected result**:
- Post appears in the feed immediately after submission.
- Comment count increments after adding a comment.
- Like count increments (and the heart turns filled/colored) after tapping like.

---

## Test 10: Analytics, Achievements, Leaderboard

**Goal**: The analytics page renders all three sections without errors.

**Steps**:
1. Navigate to the **Profile** tab.
2. Tap **Analytics** (or the chart icon).
3. Scroll through the **Activity Heatmap** — verify coloured squares appear for days with activity.
4. Tap the **Achievements** section — verify a list of earned/locked badges.
5. Tap the **Leaderboard** tab — verify a ranked list of users with XP scores.

**Expected result**:
- No blank sections or error messages.
- Heatmap shows at least today's activity if a lesson was completed in Test 3.
- Leaderboard shows the current user in the list.

---

## Test 11: Public Profile

**Goal**: Viewing another user's public profile works correctly.

**Steps**:
1. In the community feed (Discover tab), tap on any post's author avatar or name.
2. The public profile card/screen opens.

**Expected result**:
- Display name, avatar (or placeholder), XP level, and streak are shown.
- No crash or "User not found" error for a valid user.
- Back navigation returns to the feed.

---

## Test 12: Privacy Settings + Data Settings

**Goal**: User can view and toggle privacy and data options.

**Steps**:
1. Navigate to **Profile** → **Settings**.
2. Open **Privacy Settings**.
3. Toggle at least one option (e.g. "Show profile publicly").
4. Navigate back and re-open Privacy Settings.
5. Return to Settings and open **Data Settings** (or "Manage Data").
6. Verify options are listed (e.g. export data, delete account).

**Expected result**:
- Privacy toggle persists after navigating away and returning.
- Data settings screen opens without crash and lists available actions.
- No unhandled exception dialogs.
