## 数据质量问题

### 1. 派生词（derivatives）格式不一致
- **初级英语 / GMAT**：数组格式 `[]`，但全部为空
- **GRE / 雅思 / SAT / 托福**：混合使用字符串和数组
- **处理方案**：服务端加载时统一标准化为数组，空值保留为空数组

### 2. 音标覆盖率差异
- 托福、GRE、雅思覆盖率 > 99%
- SAT 音标覆盖率约 54%，原因是部分词条使用简写或省略
- **处理方案**：音标缺失时使用占位符 `[待补充]`，不影响核心学习流程

### 3. 跨本重复词
- 跨本重复词共 **5,496** 个
- **说明**：这是正常现象，不同考试之间有大量高频重叠词汇（如 abstract, approach, benefit 等）。重复词在词书切换时会由 UserWord 机制去重，不影响学习体验。

### 4. 单本重复词
- 仅 SAT 有 3 个重复词，可忽略
